## 검수 기준

색이 곧 의미다. 위탁된 것은 회색(`#C9CCD4`), 내 것은 인디고(`#2F44A8`).
회색으로 칠해야 할 요소가 인디고로 나온 이미지는 쓰지 않는다. 8장 전부 육안 검수한다.

가로세로 비율은 8장이 동일해야 한다. 결과 화면 레이아웃을 그 비율에 맞춘다.
